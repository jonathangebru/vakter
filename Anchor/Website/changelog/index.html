Changelog

What shipped, what changed, and what's still pending. Honest notes — not a marketing recap. Newest at the top.

v1.6 — coming next

Q3 2026 (target)
What's coming
  • ClickFix Paste Shield. Vakter watches for shell commands written to your clipboard by web pages. When you move to paste into Terminal, iTerm, or Warp, Vakter intercepts and shows a one-sentence plain-English explanation of what the command does — before it executes. Apple's macOS 26.1 paste warning blocks with a modal and no explanation; users habituate and dismiss it. Vakter's version explains.
  • Scope note. Vakter v1.4 watches your Mac against the physical grab. v1.6 extends the watch to the clipboard — the surface that became the second-largest macOS malware vector in 2025. Same night-watch, wider scope. Existing licences cover the update.
Nothing in v1.6 phones home. The clipboard analysis runs entirely on-device using Apple's Foundation Models framework (macOS 26+, Apple Silicon). No text from your clipboard leaves your Mac.

v1.4.3

21 May 2026
What's new
  • Stealth lock-screen takeover. On alarm, Vakter overlays a fullscreen "STOLEN — please call …" screen above the macOS lock screen. Configurable contact text and callback number. Multi-monitor aware — renders on every connected display.
  • Defenses checklist over XPC. The menubar dropdown's Defenses submenu now reflects helper-side checks in real time. Toggle Firewall in System Settings; the menubar updates within 6 seconds.
  • Onboarding teaches the alarm. The "Hear the alarm" step now plays your selected siren plus voice cue — not always the default. Camera and microphone permissions are requested during onboarding so the photo burst and ambient audio capture work on the first real alarm.
What's still pending
  • Sparkle 2 auto-update goes live with v1.5. The appcast channel is wired but uses a placeholder EdDSA key. Until the key is generated and the appcast is signed, download the latest DMG directly from vakter.app.
  • iOS + Apple Watch companions: source complete; provisioning in progress. Source compiles and CloudKit sync works. Provisioning profiles and TestFlight submission are in progress. The Mac app is complete and ships today; companions follow.

v1.4.1

20 May 2026
Overview

This is the first release under the Vakter name. The product shipped previously as Anchor — same codebase, same developer, renamed before public launch. v1.4.1 is the first build submitted to Apple for notarization and distributed as a signed DMG.

The core watch loop is complete: arm with one shortcut, and Vakter monitors lid state, power, and Bluetooth peer proximity. On any trigger, a local siren fires, a photo burst runs, and an iMessage with your location goes to the number you configured — before the lid closes.

What's new
  • Notarized DMG (4.8 MB). First build submitted to and cleared by Apple's notary service. Gatekeeper opens it without a warning dialog. Signed with Team ID 9TA5GB5UJH, Hardened Runtime enabled on all three binaries.
  • Café mode. Five operating modes now ship: Normal, Travel, Library, Loaner, and the new Café mode. Café disarms Bluetooth proximity (your AirPods are close but you want the alarm to stay live) and raises the grace window for the noisier public-space workflow — take your coffee, come back, no false alarm.
  • Bluetooth trust-lost false-positive fix. Earlier builds occasionally fired the alarm when a trusted Bluetooth peer was momentarily out of range — typical in a busy café as radios negotiate. The observer now waits for a peer to be stale for 3 seconds across continuous polling before emitting a trust-lost event. Single peer fluctuations no longer trigger the state machine.
  • Live Defenses audit in the menubar. The Defenses panel now reads 20 system-posture checks at launch — FileVault, Find My, login window message, screen-lock delay, Gatekeeper, SIP, Touch ID enrollment, SSH passphrase presence, and more. Each check that fails shows a one-tap link to the relevant System Settings pane. The audit runs read-only; Vakter never silently changes a system setting.
  • 7-language voice TTS on alarm. The spoken deterrent cue — "This Mac is protected. Step away." — now uses Apple's neural AVSpeechSynthesizer voices in seven locales: English, French, German, Spanish, Japanese, Mandarin Chinese, and Arabic. The locale is detected at alarm time from your system language preference.
  • iPhone + Apple Watch companion source (preview). The CloudKit-backed iOS and watchOS companion targets are in the repository. The iPhone app reads your alarm state and event log from your private CloudKit database; the Watch app shows the current shield state and provides a remote disarm path. These are not yet provisioned for TestFlight — see "What's still pending" below.
  • Event Log with inline photo thumbnails. Alarm events in the Event Log now display 60×60 photo thumbnails from the burst. Tap any thumbnail to open the full image in Preview.
  • Closed-lid alarm on Apple Silicon. Vakter's privileged root daemon calls pmset disablesleep 1 while armed. On Apple Silicon, macOS suspends audio routing when the lid closes unless sleep is explicitly disabled at the system level. This keeps the speakers live so the siren routes to internal audio even after the lid closes.
What's still pending
  • Sparkle auto-update not yet wired. In-app update checks require a signed appcast.xml at vakter.app/appcast.xml. For now, download the latest DMG manually from the website.
  • iOS + Watch companion not yet on TestFlight. Bundle IDs app.vakter.companion and app.vakter.companion.watchkitapp need App IDs and provisioning profiles before distribution. The source compiles; provisioning is the only gate.
  • XPC peer verification gap. The XPC connection between the menubar app and the helper does not yet enforce Team ID pinning via setCodeSigningRequirement. Any process running as the same user could, in principle, call the helper's XPC methods. Closing this is the first security fix in the next update.
  • Defenses checklist over XPC. The live audit reads correctly from inside the menubar app. It does not yet surface through the helper's XPC interface, so it won't be available to a future Shortcuts integration or a CLI tool until that plumbing is added.
Migration note. If you ran a pre-release build labelled "Anchor," your settings and event log at ~/Library/Application Support/Anchor/ migrate automatically on first launch of Vakter. The migration is one-shot and non-destructive; the original directory is left in place.
